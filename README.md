Spam Email Detection

About

This project uses Machine Learning to classify emails as spam or normal.

Technologies Used

Python

Pandas

Scikit-learn

Logistic Regression

Features

Predicts whether an email is spam or normal.

Displays spam prediction probabilities.

Evaluates the model using a confusion matrix, precision, recall, and classification report.

How to Run

Install the required libraries:
pip install pandas scikit-learn

Run the Python file:
python spam_detection.py
